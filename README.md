# Smart CRM Portal

AI-powered lead operations portal for capturing, classifying, routing, and reporting on leads.

This repository is the rebuilt v2 application for the original Smart CRM Portal. The frontend is being migrated from the previous WordPress implementation into a proper React + TypeScript codebase connected to the existing Supabase and n8n automation backend.

## Planned stack

- React + TypeScript
- Vite
- Supabase
- n8n
- Gemini-powered classification and summaries
- Vercel deployment

## Existing backend

The current Supabase project already contains the core CRM data models for leads, insights, and weekly summaries. Authentication and tenant-safe Row Level Security will be added as part of the v2 rebuild.
